# Exactitude factuelle, droit et administration France

- **0** : au moins une affirmation factuelle fausse, enoncee sans reserve
  (mauvais article de code, mauvais organisme, seuil invente, dispositif qui
  n'existe pas presente comme existant).
- **1** : le fond est a peu pres juste mais les references sont approximatives
  ou absentes la ou l'epreuve les demande.
- **2** : exact et reference, mais incomplet sur un point que l'epreuve
  demandait explicitement.
- **3** : exact, reference (texte, organisme, formulaire nomme correctement),
  complet sur ce que l'epreuve demande, et distingue ce qui est etabli de ce
  qui depend d'une appreciation.

Regle dure : une seule invention confiante plafonne la note a 0, meme si le
reste est parfait. Dans cette categorie l'erreur coute de l'argent reel.
